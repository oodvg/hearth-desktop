# Hearth Desktop

The official Hearth desktop app. It opens https://chat.oodvg.xyz in its own window, so users don't need to install Fluxer or add your instance by hand.

Features: Hearth name and icon, single instance, tray icon (closing the window hides it to the tray; quit from the tray menu), native notifications, links open in your normal browser, remembers window size and position, and a branded offline page that retries automatically.

Early Access to Hearth Desktop. Based off of Fluxer Desktop Client. Another alternative to Discord.

Fluxer is a free and open source instant messaging and VoIP chat app built for friends, groups, and communities.

# What is Hearth?

Hearth is my own small group that is built off of Fluxer. this client will ONLY connect to [Hearth](https://chat.oodvg.xyz)
